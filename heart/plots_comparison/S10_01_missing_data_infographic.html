4. GMM validation (all columns)

How GMM Validation Works?

  • A Gaussian Mixture Model (6 clusters, full covariance) learns the joint distribution of all 16 columns from 75,000 real complete records.
  • It learns patterns such as: older age → more poor-health days; higher BMI → less exercise; all variables together form clusters.
  • The log-likelihood of every completed record is compared with 75,000 held-out real records.
  • Above the 1st percentile of real records → plausible; below → flag.

Summary of the pipeline

  1. Detect missing values in the dataset (4.37% of predictor cells).
  2. Apply HyperImpute (uses all other features) to predict each gap.
  3. Obtain the completed dataset (same rows, no gaps).
  4. Validate imputed records with a GMM on all columns (multivariate check).
  5. Decide accept the imputation if plausible, otherwise flag it for inspection (4 accepted, 0 flagged).

Key takeaway

HyperImpute predicts each missing value from the relationships in the data, while the GMM confirms that every imputed record is statistically consistent with the overall multivariate distribution (all columns, not just the imputed column).
