"Before" = GE-71 data after MICE imputation (Missing Value Bias stage), still in each variable's native units — Age in years, Alb/Cre as a ratio up to ~200+, SICAM in ng/mL up to ~500+, HbA1c as a %. These wildly different magnitudes are exactly what Feature Scale Bias refers to: without correction, high-magnitude variables (SICAM, Alb/Cre) would dominate any distance-based or gradient-based model over low-magnitude ones (HbA1c, Years of DM). "After" = Quantile Transformation (rank-based, mapped onto a Normal distribution). Note: the notebook's own selection metric (lowest Wasserstein distance to N(0,1) + best correlation preservation) actually scored Z-score highest as a scaler to use — but Z-score is a straight linear rescale, so its Before/After histograms are shape-identical bin-for-bin and can't show visible overlap in a chart like this. Quantile Transformation is shown here instead purely so the Before/After bars are visually distinguishable; see its row in the comparison table on the right.
