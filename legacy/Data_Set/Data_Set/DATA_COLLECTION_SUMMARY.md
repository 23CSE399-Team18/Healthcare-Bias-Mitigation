# Data Collection — Summary

 healthcare datasets are collected to train, analyse, and evaluate ML models for fair clinical decision support.
- **UCI Heart Disease** — parameters: age, sex, blood pressure, cholesterol, ECG, heart rate, ST depression; target: heart disease; bias studied: sex.
- **CKD** —  parameters: blood chemistry, urinalysis, comorbidity flags (hypertension, diabetes, anemia); target: CKD diagnosis; bias studied: age group.
- **eICU** — parameters: demographics, diagnosis counts, aggregated lab results; target: ICU mortality; bias studied: gender × ethnicity.
- **NHANES** -  parameters: age, gender, race/ethnicity, income, education;
