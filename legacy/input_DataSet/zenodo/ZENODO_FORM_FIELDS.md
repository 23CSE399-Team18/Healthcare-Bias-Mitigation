## Description

Tabular datasets for three diseases (diabetes, heart disease and hypertension),
prepared between 2024 and 2026 for detecting and mitigating data bias in
healthcare machine learning. The record contains diabetes hospital encounters
(101,766 rows, 71,518 patients), heart-disease survey responses (440,111 rows)
and hypertension Holter ECG features (72,110 two-minute windows from 105
patients). README.md describes every column and how each file was prepared.
