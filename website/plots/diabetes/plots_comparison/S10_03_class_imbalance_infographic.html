4. GMM validation (all columns)

How GMM Validation Works?

  • A GMM (4 clusters) learns the joint distribution of all 7 columns of the REAL cases only.
  • Every synthetic case is scored under that model: a realistic case has a likelihood like real cases.
  • Over all 3,805 synthetic cases, 99.3% pass the 1st-percentile threshold of real held-out cases.
  • Passing rows are plausible new cases; failing rows lie outside the real-case clusters.

Summary of the pipeline

  1. Detect the class imbalance (6.07 : 1).
  2. Apply TabDDPM (diffusion model trained on real cases) to generate new cases.
  3. Obtain the balanced training set (1 : 1).
  4. Validate every synthetic case with a GMM of real cases on all columns.
  5. Decide accept realistic synthetic cases, flag the rest (99.3% of all synthetic rows accepted).

Key takeaway

TabDDPM creates new minority-class records from the learned distribution of real cases, while the GMM confirms that the synthetic cases are statistically consistent with real cases across all columns.
