4. Domain-classifier validation

How Domain Validation Works?

  • A new multinomial classifier (5-fold CV, 18,569 training rows) predicts the region from all columns.
  • Macro AUC: 0.60 from the original features → 0.56 from z1…z32.
  • The pipeline's own metrics (left) compare no adaptation with the DG transformer on shift and accuracy.
  • Record rule: P(own region) ≤ chance + 0.15 = 0.40 → the record no longer reveals its region.

Summary of the pipeline

  1. Detect region-dependent feature distributions (domain shift).
  2. Apply the domain-generalisation transformer (32-dim representation).
  3. Obtain the domain-invariant representation.
  4. Validate a fresh domain classifier on all 32 dimensions.
  5. Decide accept records whose region is hidden, flag the rest (4 accepted, 3 flagged).

Key takeaway

The DG transformer makes the region harder to recognise (domain AUC 0.60 → 0.56 here; pipeline 0.584 → 0.526) while keeping hypertension accuracy, but the domain classifier shows a small region signal remains, so a few records are still flagged.
