4. Adversary validation

How Adversary Validation Works?

  • A new logistic-regression adversary (5-fold cross-validation, 5,307 real training rows) tries to recover sex and race.
  • Sex AUC: 1.00 from the original features → 0.94 from the representation; race AUC 0.68 → 0.68.
  • Pipeline fairness metrics (left plot): SPD 0.162 → 0.141, DID 0.435 → 0.343, EOD 0.133 → 0.070, Equalized-odds difference 0.138 → 0.161 (lower = fairer).
  • Record rule: if the adversary gives ≤ 0.65 to the true sex, the record no longer reveals it.

Summary of the pipeline

  1. Detect group gaps in outcome rate and model errors.
  2. Apply adversarial debiasing to learn a 32-dim group-blind representation.
  3. Obtain the fair representation for every record.
  4. Validate a fresh adversary on all 32 dimensions (sex and race).
  5. Decide accept records whose group is hidden, flag the rest (1 accepted, 9 flagged).

Key takeaway

Adversarial debiasing narrows the group gaps the pipeline measures (SPD 0.162 → 0.141, EOD 0.133 → 0.070), but the adversary check shows the representation is not group-blind: sex is still recoverable (AUC 0.94) and race unchanged (AUC 0.68). The fairness gain comes from the debiased predictor, not from hiding the groups.
